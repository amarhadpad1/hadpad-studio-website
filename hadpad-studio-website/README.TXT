HADPAD STUDIO — EDITORIAL EDITION

1. Open this folder in VS Code.
2. Open index.html with Live Server, or double-click index.html.
3. Edit index.html for text and links, style.css for design, script.js for contact-form behaviour.
4. Images are stored in images/ and preserved from your uploaded website.

Existing portfolio URLs, contact email, phone, WhatsApp, and Google Apps Script enquiry endpoint are retained.
The Shan Kirana customer storefront and admin dashboard have separate visible links.
The two Shan Kirana links use the same existing deployed app; this redesign does not change its database.

IMPORTANT: Google Apps Script is called using no-cors mode. The browser cannot verify that the form submission reached your spreadsheet. Test an enquiry and check your spreadsheet before publishing.

The Google Fonts link needs internet to load the intended fonts; system fonts are used as fallbacks.
